Sobre el dispositivo

¿De qué se trata este dispositivo?

Este módulo es el corazón de nuestra economía circular. Convierte la materia en energía limpia y conversa todo el tiempo con la red que lo rodea. Acá nada se desperdicia, cada residuo vuelve al sistema como nutriente o como recurso para la ciudad.
